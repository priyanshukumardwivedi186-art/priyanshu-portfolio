# Priyanshu Kumar Dwivedi — Personal Portfolio

A responsive personal portfolio website built with HTML5, CSS3, JavaScript, Bootstrap 5, and Bootstrap Icons.

## Features
- Responsive layout for mobile, tablet, and desktop
- Dark/light theme toggle
- About, skills, projects, education, and contact sections
- Accessible navigation, labels, and form status messages
- Contact form prepares an email using the visitor's default email app
- Reduced-motion support and current year in footer

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Internet access is required for Bootstrap and Bootstrap Icons CDN assets.

You can also open the folder in Visual Studio Code and use the Live Server extension.

## Customize
- Update personal details and project descriptions in `index.html`.
- Edit colors and layout in `css/style.css`.
- Update theme and contact form behavior in `js/app.js`.

## Important
The contact form does not use a backend and does not send or store messages itself. It opens a `mailto:` draft in the visitor's email application. Public project/demo links can be added when available.
